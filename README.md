# 콕매치 — 정적 배드민턴 대진표

`index.html`을 브라우저로 열면 바로 사용할 수 있는, 서버 없는 복식 배드민턴 대진표 생성기입니다. 참가자 명단은 줄바꿈이나 쉼표로 입력하며, 브라우저 밖으로 전송되지 않습니다.

## 제공 기능

- 코트 수와 라운드 수에 맞춘 복식(4인) 대진 자동 생성
- 출전·휴식 횟수 균등 배분, 3라운드 연속 출전 회피, 파트너·상대 중복 최소화
- 중복 및 유사 닉네임 알림
- 라운드별 표와 개인별 출전·휴식·연속 출전 검증표
- 모바일 화면, 인쇄/PDF, CSV 저장, 텍스트 복사 및 기기 공유

모든 조건이 수학적으로 동시에 가능하지 않은 경우(예: 참가자 4명으로 여러 라운드 진행)는 화면에 이유를 표시합니다. 대진은 각 생성 시 여러 후보를 비교해 가장 균형적인 결과를 선택합니다.

## 배포

별도의 빌드 과정은 없습니다. 아래 파일을 같은 폴더에 유지한 채 정적 호스팅에 올리면 됩니다.

- `index.html`
- `styles.css`
- `app.js`

### GitHub Pages

1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 원본을 `main` 브랜치의 `/ (root)`로 선택합니다.
3. 표시되는 사이트 주소로 접속합니다.

### Netlify 또는 Cloudflare Pages

프로젝트 폴더를 새 사이트로 드래그해 올리거나 저장소를 연결합니다. 빌드 명령과 출력 폴더는 모두 비워 둡니다. 정적 파일이므로 서버 설정은 필요하지 않습니다.

## 운영 메모

- 라운드 수를 비우면 8라운드가 기본으로 적용됩니다.
- 코트가 있어도 참가자가 4명 단위로 부족하면 사용 가능한 코트 수만 운영합니다.
- 닉네임은 대진표·검증표에서 입력한 철자 그대로 유지됩니다. 유사 표기 경고가 나오면 시작 전 명단을 확인하세요.
